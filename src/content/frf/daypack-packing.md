  **⏱ 閱讀時間：** 約 8 分鐘

## 📍 背包越輕，你的戰鬥力越強。

富士搖滾的現場，什麼都有可能發生——
下雨、爆熱、泥地。背包裡的每一個小物，都是你的救命稻草！

這篇不談大道理，直接公開 **真正有上場經驗的老手**，那顆 15L 的小背包裡到底藏了什麼？

![](/images/frf-posts/daypack-packing/image-01.webp)

### 1️⃣ 核心容器：10–20L 小型背包

別帶太大的包！相信我，在綠舞臺的人潮中，一個巨大的登山包只會讓你寸步難行。(太大安檢處也不讓你過)

- **黃金尺寸：** **10L - 20L**。
- **挑選重點：**
  - **輕巧好走：** 夠裝雨衣、水壺、錢包即可。
  - **能被雨衣罩住：** 這是關鍵！當穿上斗篷雨衣時，背包必須能完全躲在雨衣裡面，這是最完美的防水方案。
- **鐵律：** **太大太重 ＝ 下雨泥地會想哭**。

### 2️⃣ Heroclip 萬能掛勾（神物推薦）

如果只能推薦一個「非必需但超好用」的小物，絕對是這個。

- **用途：**
  - **掛背包：** 進流動廁所時，不想把包包放在髒濕的地板上？掛在門板上。
  - **掛雨衣：** 雨停了，濕答答的雨衣沒地方放？掛在背包外曬乾。
  - **解放雙手：** 買了啤酒、炒麵、周邊，手忙腳亂時，一個掛勾救全場。
- **規格：** 建議買 **M 號**，承重夠強且開口夠大，能扣住粗欄杆。

### 3️⃣ 防水手機袋 ＋ 保溫瓶

- **防水手機袋：**
  - 富搖現場下雨是基本盤，手機沒保護會心痛到爆。
  - 建議買有 **「掛繩」** 的款式，掛在脖子上隨時拍照、看時間，不用一直翻包包。
- **保溫瓶：**
  - 別懷疑，帶一個輕量的保溫瓶。
  - **裝熱飲：** 會場有保溫瓶的帳篷有提供熱水，天氣熱沒人但氣溫若稍濕冷一下就被倒完了。
  - **裝冷飲：** 白天裝冰塊水，不用一直花錢買攤販的小瓶水。

### 4️⃣ 小物補給包（救命三寶）

- **濕紙巾：** 擦手、擦汗、擦泥巴、擦餐具。建議買 **「純水」** (洗臉用) 和 **「酒精」** (消毒用) 各一包。
- **涼感濕巾：** GATSBY 或 Biore 的極凍濕巾。在 35 度高溫下擦下去，你會看見天堂。
- **降噪耳塞：** 有效保護脆弱的耳朵。站在音箱前太久耳朵會受不了，戴上耳塞一樣能享受重低音，但不會耳鳴。

### 5️⃣ 防蚊裝備 ＋ 防曬小物

- **防蚊：** 苗場有種叫 **「Buyo (蚋)」** 的吸血蟲，咬到會腫很大包。
  - **必備：** 含 **Icaridin** 或 **DEET** 成分的防蚊噴霧，隨時補噴。
- **防曬：**
  - **涼感防曬乳：** 記得補擦，陰天的紫外線也很毒。
  - **小型風扇：** 在大太陽底下排周邊或等接駁車時，不靠它真的會融化。建議買有 **「掛勾」** 或 **「掛繩」** 的款式。

![](/images/frf-posts/daypack-packing/image-02.webp)

> 🧊 讓我撐過三天的救命保冰包：我將冷凍的寶礦力軟包+底層冰塊磚+濕紙巾+涼感紙巾一同裝入，到下午三點都還有冰水可用。(角瓶請忽略，不能帶玻璃瓶罐進場)

### ✅ 終極檢查表（Check List）

出門前，請逐一勾選：

- [ ] **現金/IC卡** (分開放，雞蛋別放同個籃子)
- [ ] **手機 + 防水袋**
- [ ] **行動電源** (含短線)
- [ ] **雨衣/斗篷**(氣象預報無論有沒有預告，帶就是了)
- [ ] **水壺/保溫瓶**
- [ ] **Heroclip 掛勾**
- [ ] **濕紙巾 + 面紙**
- [ ] **防蚊液 + 防曬乳**
- [ ] **小風扇**
- [ ] **頭燈** (晚上走山路必備)

## ⚡ 懶人重點整理

> ⚡ **本篇 5 個帶走重點：**

  1. 背包黃金尺寸 **10–20L**，太大在人潮中尺步難行（超大包安檢可能不讓進）
  2. **Heroclip 掛勾**：廁所「不被地板」、曬濕雨衣、解放雙手，一個解決三個問題
  3. **防水手機袋掛繩款**：不用翻包包就能拍照看時間
  4. **防蚊液選 Icaridin 或 DEET 成分**，普通驅蚊液無效
  5. 手機、錢包、行動電源用**夾鏈袋**再裝一層，是最便宜的防水神技
